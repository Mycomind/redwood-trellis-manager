# Redwood Trellis Manager — Shop Setup Checklist

## First-time setup

1. Open the app.
2. Go to Settings.
3. Set lumber cost, waste percentage, hardware cost, labor rate, markup, and wholesale discount.
4. Click Save settings.
5. Click Export backup.

## Product catalog setup

1. Go to Products.
2. Edit starter trellis sizes to match real products.
3. Verify width, height, stock thickness, slat width, slat counts, labor minutes, retail price, and wholesale price.
4. Delete anything Dennis does not sell.

## Quote workflow

1. Create quote.
2. Apply product price.
3. Adjust quantity, deposit, and notes.
4. Save quote.
5. Print or copy quote.
6. Convert accepted quote into job.

## Job workflow

1. quoted
2. deposit paid
3. building
4. ready
5. delivered
6. paid

## Backup rule

Export a backup at the end of every real workday.
